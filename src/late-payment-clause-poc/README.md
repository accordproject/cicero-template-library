# Late Payment (next major release prototype)

A reusable late payment clause, built on the design for the next major
release of the Accord Project stack. It is a template of its own, and a
parent composes it into a slot through the interface it implements. It is
the late payment clause of
[`copyright-license-agreement-poc`](../copyright-license-agreement-poc),
the running example of The Agreement Quarter. It is a **draft**, and it
runs only against a checkout of the next-major engine.

## The interface

[`model/latepayment.api.cto`](./model/latepayment.api.cto) is
`org.accordproject.latepayment.api@1.2.0`. An interface is a versioned
namespace: every non-abstract transaction that extends `Request` is a
member, and each member describes itself.

| Member | Answers | May decline with | Notifies |
| --- | --- | --- | --- |
| `PaymentOverdue {obligor, obligee, amount, dueAt}` | `ReminderSent {reminder, nextReminderAt?}` | `ReminderLimitReached {remindersSent}` | `LateFeeAccrued` |
| `PaymentSettled` | `LatePaymentCleared {remindersSent}` | (never declines) | |

A parent's slot asks for the interface with a semver range, as the licence
does with `"interface": "org.accordproject.latepayment.api@^1.0.0"`. This
clause implements 1.2.0, which that range accepts. The interface would be
published on its own. Until then it ships here, with the clause that
implements it, and the engine loads it beside every archive of the
agreement. A parent's logic is typed from it: the licence's codegen
generates it into the licence's `logic/generated/` as well.

## The clause

| File | What it holds |
| --- | --- |
| `model/model.cto` | `LatePaymentData` (`reminderLimit`, `reminderIntervalDays`, `lateFee`, plus the `utcOffset` the parent binds), `LatePaymentState`, and the `PaymentReminder` effect |
| `text/grammar.md` | The clause text. The parent drafts it in place where its grammar says `{{#clause latePayment}}{{/clause}}` |
| `logic/logic.ts` | `PaymentOverdue` sends the next reminder as an effect, keeping it pending, and accrues the late fee with the first. `PaymentSettled` stops the reminders. `onOutcome(PaymentReminder)` clears a pending reminder |
| `logic/helpers.ts` | `formatAmount`, for the grammar, and `addDays`, for the next reminder date |
| `sample.json` | Three reminders, seven days apart, and a USD 25.00 late fee |
| `logic/generated/` | Generated by the licence's `npm run compile` |

The clause counts reminders sent, not reminders delivered. A reminder the
host could not deliver still counts. The clause says when the next reminder
is due, but it sets no timer of its own: the parent decides when to ask
again.
