# Licensed Work Schedule (agreement@1.0.0 document prototype)

Schedule 1 to the copyright licence in
[`copyright-license-agreement-poc`](../copyright-license-agreement-poc): a
second document in the same agreement, describing the licensed work. It is a
stateless document template, with no `StateData` subtype and no logic, so it
has no entry in the agreement's state. The licence reads its title as a
cousin document.
